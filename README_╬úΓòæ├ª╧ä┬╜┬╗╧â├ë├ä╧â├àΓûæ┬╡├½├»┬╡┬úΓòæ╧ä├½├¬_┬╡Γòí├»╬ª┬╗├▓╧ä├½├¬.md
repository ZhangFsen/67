# 云端用户管理器 Pro 手机版测试版 v1.0.2

本版本基于你提供的 Android WebView 模板修改。

## 本次优化

1. 用户管理页优化：搜索框单独一行，刷新与筛选分开，不再挤成一排。
2. 状态筛选改为自定义底部弹窗，适配手机竖屏。
3. 所有 alert / confirm / prompt 都改为自定义弹窗，不再使用系统默认提示框。
4. 添加/编辑项目改成一次性填写全部字段：软件名称、后台地址、读取用户接口、执行操作接口、Admin Token、备注。
5. 空数据状态改为卡片式提示，并提供刷新按钮。
6. 操作成功/失败统一使用自定义弹窗。

## 使用说明

首次打开时输入至少 6 位管理密码。进入项目管理后，检查 Base URL、users_path、action_path、Admin Token 是否与云函数一致。保存项目后点击仪表盘的“刷新用户数据”。

默认接口字段保持与你的 Python 桌面版一致：

- base_url
- users_path
- action_path
- admin_token
